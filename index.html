SHORTS MAKER

영상 제작 스튜디오 · 사라진 시간들

주제 발굴실

최근 유튜브 영상의 조회수를 비교해 소재를 찾아. 실제 조회수 데이터 검색은 YouTube Data API 키가 필요해. 키가 없어도 유튜브와 Google 트렌드 검색은 이용할 수 있어.

브라우저에만 저장돼. Google Cloud에서 YouTube Data API v3를 켜고 HTTP 리퍼러 제한을 설정해.

채널 주제 바로 검색

1. 영상 제목과 대본

채널명 ‘사라진 시간들’은 영상 제목에 자동으로 들어가지 않아. 매 영상의 주제를 입력해.

2. 폰트 설정

폰트를 업로드하면 이 브라우저에 저장돼.

3. 음성 TTS

API 키 없이 브라우저에 설치된 음성으로 읽어줘. 음성 종류는 컴퓨터와 브라우저에 따라 달라질 수 있어.

4. 장면 편집

큰 제목은 고정돼. 아래에서 장면별 작은 설명, 강조색, 이미지를 수정할 수 있어.

영상 미리보기

대본을 입력하고 장면을 만들어줘.

영상 다운로드

5. 영상 디자인

미리보기에서 제목과 자막을 끌어 위치를 바꿀 수 있어. 자막은 가로 폭에 맞춰 자동 줄바꿈돼.

디자인 세부 규격

제목과 설명 자막의 모양을 각각 설정해. 저장한 프리셋은 다음 영상에도 그대로 쓸 수 있어.

6. 영상 설명란 템플릿

영상마다 설명란의 구조를 통일해. 내용만 바꾸고 복사해서 유튜브에 붙여넣으면 돼.
