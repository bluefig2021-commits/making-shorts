SHORTS MAKER

영상 제작 스튜디오 · 사라진 시간들

주제 발굴실

최근 유튜브 영상의 조회수를 비교해 소재를 찾아. 실제 조회수 데이터 검색은 YouTube Data API 키가 필요해. 키가 없어도 유튜브와 Google 트렌드 검색은 이용할 수 있어.

브라우저에만 저장돼. Google Cloud에서 YouTube Data API v3를 켜고 HTTP 리퍼러 제한을 설정해.

채널 주제 바로 검색

1. 영상 제목과 대본

자막 길이는 글자 수로 자동 계산돼. 아래 자막 목록과 타임라인에서 초 단위로 바꿀 수 있어.

2. 폰트 설정

폰트를 업로드하면 이 브라우저에 저장돼.

3. 음성 TTS (미리 듣기용)

브라우저에 설치된 음성으로 읽어줘. 영상에는 소리가 들어가지 않아.

4. 미디어 (이미지·영상)

이미지와 영상 클립을 여러 개 올려. 올린 순서대로 미디어 트랙에 이어 붙어. 영상은 길이가 모자라면 반복 재생돼.

자막 카드의 "여기서 새 이미지 시작"에 체크된 자막부터 다음 미디어로 넘어가는 걸로 계산해.

5. 자막 편집

자막마다 길이(초)를 따로 정해. 이미지 1장에 자막 여러 개를 넣고 싶으면 "새 이미지 시작" 체크를 빼면 돼.

6. 미리보기 · 타임라인

0.0초 / 1.0초
🖼 미디어 트랙 (파랑=이미지, 초록=영상)
💬 자막 트랙 (노란 줄 = 새 이미지 시작)

대본을 입력하고 자막을 만들어줘.

영상 만드는 동안엔 이 탭을 계속 켜둬야 해. (실시간으로 녹화돼)

영상 다운로드

영상 디자인

미리보기에서 제목과 자막을 끌어 위치를 바꿀 수 있어. 자막은 가로 폭에 맞춰 자동 줄바꿈돼.

디자인 세부 규격

제목과 설명 자막의 모양을 각각 설정해. 저장한 프리셋은 다음 영상에도 그대로 쓸 수 있어.

영상 설명란 템플릿

영상마다 설명란의 구조를 통일해. 내용만 바꾸고 복사해서 유튜브에 붙여넣으면 돼.
