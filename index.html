Shorts Maker

1. 영상 제목과 대본

여기에 입력한 제목은 모든 장면에서 동일하게 표시돼.

2. 폰트 설정

폰트를 업로드하면 이 브라우저에 저장돼.

3. 음성 TTS

API 키 없이 브라우저에 설치된 음성으로 읽어줘. 음성 종류는 컴퓨터와 브라우저에 따라 달라질 수 있어.

4. 장면 편집

큰 제목은 고정돼. 아래에서 장면별 작은 설명, 강조색, 이미지를 수정할 수 있어.

5. 영상 디자인

미리보기에서 큰 제목이나 설명 자막을 마우스로 끌어 위치를 바꿀 수 있어.

6. 영상 미리보기

대본을 입력하고 장면을 만들어줘.
